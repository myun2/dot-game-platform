# Dot Game Platform

GB風プラットフォーム (Generated by Claude)

![開発画面。左が実機、右がコードエディタ](docs/screenshot.jpg)

```
open index.html            # そのままでも動く
python3 -m http.server 8947 && open http://localhost:8947/
```

## 本体の仕様

| 項目 | 内容 |
| --- | --- |
| 画面 | 160×144 ピクセル、4 階調（0 = 明るい 〜 3 = 暗い）、60fps |
| スプライト | 8×8 のタイル 256 枚（128×128 のシート 1 枚）。色 0 は透明 |
| マップ | 64×64 タイル。タイルごとに 8 ビットのフラグ |
| サウンド | 4 チャンネル。矩形波 50% / 25%・三角波・ノイズ。効果音 32 個 × 16 ステップ、C3〜B6 |
| 入力 | 十字キー、A、B、START、SELECT |
| セーブ | 数値 16 個（カートリッジ名ごとに localStorage） |
| 言語 | 専用の言語。`init { }` / `update { }` / `draw { }` のブロックを本体が呼ぶ。変数は 4096 個まで |

キーボードは 矢印 = 十字キー、`Z` = A、`X` = B、`Enter` = START、`Shift` = SELECT。

## 使いかた

- **コード** — `Ctrl/⌘ + Enter` で実行。書いているそばから文法を確かめ、文法エラーはその行に出る。実行時エラーも行番号つきでログに出て、クリックでその行へ飛ぶ。
- **スプライト** — 左のシートでタイルを選び、右で描く。8×8 と 16×16 を切り替えられる。右クリックで色を拾う。
- **マップ** — タイルを選んで塗る。右クリックでマップ上のタイルを拾う。赤い枠が 1 画面ぶん。
- **サウンド** — マスに音を置く。下の帯で音量。`sfx n, ch, 1` でループさせれば BGM になる。
- **ヘルプ** — API の一覧。
- 編集内容は自動でブラウザに保存される。`保存 (.json)` でファイルに、`HTML 書き出し` でそれ 1 枚で遊べる HTML になる（スマホではタッチ操作）。

## 言語

ブロックの中に、アセンブラ風の命令（`命令 引数, 引数`）を 1 行ずつ並べて書く。命令は小文字（大文字と小文字は区別しない）。

```
consts {
  SPEED = 1.5            # 定数
}

variables {
  x = 10, y              # 変数（小数も使える。値を省くと 0）
}

update {                 # 毎フレーム
  if (btn RIGHT) {
    x = x + SPEED
  }
  x = min(x, SCREEN_W - 8)
}

draw {
  cls 0
  spr 1, x, 60
  print "X ", 2, 2, 3
  print x                # 座標を省くと続きに書く
}
```

- 宣言: `consts { }` と `variables { }`。配列は `xs[8]` / `xs = [1, 2, 3]`。初期値は起動時に入り、`reset` でいつでも全部戻せる。
- ブロック: `init { }` `update { }` `draw { }` を本体が呼ぶ。自分で作ったブロックは `call 名前` で呼び、`ret` で途中から戻る。
- 代入は `x = 値`。式は `+ - * / %`、かっこ、`int abs min max rnd`、`TIME`。命令の引数にも書ける。
- 流れ: `if (条件) { } else if (条件) { } else { }`、`while (条件) { }`、`for (i: 0..9) { }`。
- システム定数: `LEFT RIGHT UP DOWN A B START SELECT`（ボタン）、`SCREEN_W` `SCREEN_H`（160、144）、`TIME`（起動からのフレーム数）。
- 条件: `== != < <= > >=`、`btn LEFT`、`btnp A`、`not` / `and` / `or`。
- 命令: `add sub mul div mod inc dec neg cls pset pget line rect rectf circ circf spr map print camera pal mget mset fget reload sfx srand dget dset log reset`

命令の一覧は画面の「ヘルプ」タブ、実例は同梱サンプル（`DOT JUMP` / `HELLO`）を参照。

## 構成

本体は画面にも音にも依存しないので、Node からそのまま読んでヘッドレスで回せる。

| ファイル | 役割 |
| --- | --- |
| `core.js` | 本体。言語の処理系、描画、フォント、音のシーケンス、カートリッジの読み書き |
| `audio.js` | WebAudio の 4 チャンネル音源。本体から「このチャンネルをこの音で」を受け取るだけ |
| `player.js` | 実機の見た目、キー / タッチ入力、60fps のループ、単体 HTML の書き出し |
| `carts.js` | 新規作成のひな形と同梱サンプル |
| `editor.js` | 開発画面 |
| `tests/core.cjs` | 本体と同梱カートの検査 |
| `bundle.cjs` | 全部を 1 枚の HTML にまとめる（公開用） |

```
node tests/core.cjs          # 検査
node tests/core.cjs --dump   # サンプルの画面を文字で出す
```

```
node bundle.cjs dot.html            # どこにでも置ける 1 枚の HTML
node bundle.cjs dot.html --hosted   # ファイル保存が効かない埋め込み型ホスティング向け（外枠なし・保存ボタンなし）
```

カートリッジ（`.dot.json`）は `{ dot, title, palette, code, gfx, map, flags, sfx }` の JSON。
`gfx` は 2 ピクセルを 16 進 1 桁、`map` と `flags` は 1 バイトを 16 進 2 桁で並べ、末尾のゼロは省く。

## 知っておくこと

- update と draw はそれぞれ 1 フレーム 20 万命令まで。超えると「無限ループ？」のエラーで止まる（タブは固まらない）。
- ブロックに引数やローカル変数はない。値は変数で受け渡す。
- `{` のあとは改行し、`}` は行の先頭に書く（`if (x) { y = 1 }` のような 1 行書きはできない）。
- `A` `B` などのボタン名と命令名は、変数やブロックの名前に使えない。
- 以前の言語（JavaScript、ラベル式のアセンブリ）で書いたカートリッジは動かない。
- 文字は英大文字・数字・記号だけ。かなは描けない。
- マップの編集は次の実行から反映される。スプライトは実行中でもすぐ反映される。

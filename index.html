本体の仕様

        

          
画面160×144 ピクセル、4 階調（0 = 明るい 〜 3 = 暗い）、毎秒 60 フレーム

          
スプライト8×8 ピクセルのタイルが 256 枚（16×16 に並んだ 1 枚のシート）

          
マップ64×64 タイル

          
サウンド4 チャンネル。効果音 32 個、各 16 ステップ、音域は C3〜B6

          
ボタンLEFT RIGHT UP DOWN A B START SELECT

          
変数4096 個まで（配列の要素も 1 個と数える）。数は小数も使える

          
セーブ数値 16 個

        


        
プログラムの形


consts {
  SPEED = 1.5            # 定数
}

variables {
  x = 10, y              # 変数（値を省くと 0）
}

init {                   # 起動時に 1 回
}

update {                 # 毎フレーム（計算）
  if (btn RIGHT) {
    x = x + SPEED
  }
}

draw {                   # 毎フレーム（描画）
  cls 0
  spr 1, x, 60
}

        
ブロックの中に 1 行 1 命令で書く。# から行末まではコメント。命令は小文字で書く（大文字でも動く）。
{ のあとは改行し、} は行の先頭に書く。ブロックや宣言を書く順番は自由。


        
変数と値

        

          
variables { x, y = 5 }変数を作る。カンマか改行で区切り、値を省くと 0。値は起動時に入る

          
resetすべての変数を variables に書いた値に戻す（ゲームのやり直しに使う）

          
xs[8] / xs = [1, 2, 3]variables の中で配列を作る。xs[0]、xs[i + 1] のように使う

          
consts { N = 8 * 16 }定数に名前をつける

          
x = 値代入する。x = y * 2 + 1

          
値10 -3 0.25 $FF 'A'、変数、+ - * / % とかっこの式。命令の引数にも式を書ける

          
int(v) abs(v)小数点以下の切り捨て、絶対値

          
min(a, b) max(a, b)小さいほう、大きいほう。max(0, min(x, 152)) で範囲に収める

          
rnd(n)0 以上 n 未満の整数の乱数

          
add sub mul div mod 変数, 値変数に足す・引く・掛ける・割る・余りにする（x = x + 1 と書いても同じ）

          
inc 変数 / dec 変数 / neg 変数+1、-1、符号を逆に

        


        
システム定数

        

          
LEFT RIGHT UP DOWN十字キー（値は 0、1、2、3）。btn LEFT のように使う

          
A BA ボタン、B ボタン（4、5）

          
START SELECTSTART、SELECT（6、7）

          
SCREEN_W SCREEN_H画面の幅と高さ（160、144）

          
TIME起動からのフレーム数（毎フレーム 1 ずつ増える。60 で 1 秒）

        

        
はじめから使える名前で、どれも大文字で書く。値は変えられず、同じ名前の変数や定数は作れない。


        
流れ

        

          
if (条件) { … } else if (条件) { … } else { … }条件で分ける。else は省ける

          
while (条件) { … }条件が成り立つあいだ繰り返す

          
for (i: 0..9) { … }変数を 1 ずつ増やしながら繰り返す（9 も含む）

          
条件x == 1 != < <= > >=、btn LEFT（押されている）、btnp A（いま押された）。not and or でつなげる

          
名前 { … }自分のブロック（サブルーチン）を作る

          
call 名前ブロックを呼ぶ。終わると呼んだ場所へ戻る。引数はないので変数で受け渡す

          
retブロックの途中で戻る

        


        
描画

        

          
cls c画面を色 c で塗りつぶす

          
pset x, y, c / pget 変数, x, y1 ピクセルを描く / 読む

          
line x0, y0, x1, y1, c線

          
rect x, y, w, h, c / rectf四角形の枠 / 塗り

          
circ x, y, r, c / circf円の枠 / 塗り

          
spr n, x, y, 反転, w, hタイル n を描く（色 0 は透明）。反転は 1 = 左右、2 = 上下、3 = 両方。w, h はタイル数。n, x, y 以外は省ける

          
map mx, my, x, y, w, hマップの (mx, my) から w×h タイルを (x, y) に描く。引数なしで全体

          
print "文字", x, y, c
print 値, x, y, c		文字や数を描く（英大文字・数字・記号、1 文字 4×6）。x, y を省くと直前の続きに書く

          
camera x, y以降の描画をずらす（スクロール）。引数なしで戻す

          
pal from, to以降の描画で色を置き換える。引数なしで戻す

        


        
マップ・音・そのほか

        

          
mget 変数, x, y / mset x, y, nマップのタイル番号を読む / 書く（x, y はタイル単位。実行中だけの変更）

          
fget 変数, n, bitタイル n のフラグ（1 / 0）。bit を省くと 8 ビットまとめた数

          
reloadマップをカートリッジの状態に戻す

          
sfx n, ch, loop効果音 n を鳴らす。ch を省くと空きチャンネル。sfx -1 で全停止

          
dget 変数, i / dset i, 値セーブデータ（i は 0〜15）を読む / 書く

          
srand 値乱数の種を決める

          
log 値, "文字", …本体の下のログ欄に出力する（デバッグ用）

        

        
座標に小数を渡すと切り捨てて描く。1 フレームに実行できるのは update と draw それぞれ 20 万命令までで、超えるとエラーで止まる。
